# ⛏️ ExcaMate

**Mine faster. Stay vanilla.**

ExcaMate is a smart mining companion for Minecraft (Fabric) that enhances how you mine without breaking vanilla balance.  
With a single key, you can vein mine, create clean branch tunnels, or excavate 3×3 areas with precision.

---

## 🚀 Features

- Hold-to-activate mining (no toggling)
- Multiple mining modes:
  - **Vein** – mines connected blocks (ores, logs, etc.)
  - **Branch (1×2)** – perfect for strip mining
  - **ExcaMate (3×3)** – clears large areas quickly
- Tool-aware behaviour (pickaxe, axe, shovel)
- Automatically stops before your tool breaks
- Supports Unbreaking
- Respects Silk Touch & Fortune (vanilla behaviour)
- Direct XP collection (no orbs) *(optional)*
- Auto-pickup items *(optional)*
- Optional torch placement in tunnels
- Configurable per-mode block limits
- Works in multiplayer

---

## 🎮 Controls

- **Hold ExcaMate key** → Activate mining  
- **Cycle ExcaMate Mode key** → Switch between modes  

### Setting Keybinds
1. Open **Options → Controls**
2. Scroll to the **ExcaMate** category
3. Set your preferred keys

---

## 🔄 Mining Modes

- **Vein**  
  Mines connected blocks of the same type.

- **Branch (1×2)**  
  Creates a 1-wide, 2-tall tunnel in front of you.

- **ExcaMate (3×3)**  
  Mines a 3×3 area based on where you're looking.

---

## 📦 Auto Pickup & XP

- Items can be sent directly to your inventory  
- XP can be collected instantly without spawning orbs  
- Both features are configurable  

---

## ⚙️ Configuration

ExcaMate generates a config file where you can customise:

- Max blocks per mode (Vein, Branch, ExcaMate)
- Auto-pickup behaviour
- XP handling
- Torch placement

---

## ⚖️ Balanced Gameplay

ExcaMate is designed to feel like vanilla Minecraft:

- No boosted drops
- No bonus XP
- Uses normal durability
- Applies exhaustion/hunger
- Respects vanilla mechanics

---

## 🔒 Safety

ExcaMate will not mine protected or sensitive blocks such as:

- Chests / containers
- Spawners
- Bedrock
- Command blocks
